# Brand Assets Intake

이 폴더는 **새로 전달받는 승인 자산의 접수 위치**이며 현재 운영 로고의 원본 위치가 아닙니다. 지금 사용하는 위브 로고와 의미·사용 기준은 프로젝트 루트의 [`brand-guidelines.md`](../../brand-guidelines.md), 실제 배포 자산은 [`public/brand/`](../../public/brand/)에서 확인하세요.

Put only approved, shareable brand assets here. Do not add account credentials, private
participant data, unlicensed images, or social-platform access tokens.

## Requested Files

| Path | Preferred format | Purpose |
| --- | --- | --- |
| `logo/mark.svg` | SVG | Small mark, favicon, mobile navigation |
| `logo/wordmark.svg` | SVG | Header and formal introduction |
| `logo/lockup.svg` | SVG | Combined mark and Korean name |
| `images/` | WebP, AVIF, or high-resolution original | Approved activity and community imagery |
| `fonts/` | Licensed WOFF2 | Only if a non-system Korean font is officially approved |
| `brand-guidelines.md` | Markdown or PDF | Colors, clear space, prohibited use, attribution |

## Minimum Information If Files Are Not Ready

- Official Korean and English name
- Primary, secondary, and accent colors as hex values
- Whether the existing youth blue is mandatory and which exact value to use
- Required or forbidden religious symbols, motifs, and image treatments
- Whether photos can be cropped, color-graded, or used as background imagery
- Image owner, intended visibility, and reuse permission for every supplied photo

## Delivery Options

1. Attach the assets in chat.
2. Place them in this folder and tell Codex the path.
3. Provide an existing local folder path; Codex will inspect only the approved files.
