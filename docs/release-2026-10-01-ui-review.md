# 화면 리뷰와 오픈 안내 반영 결과

2026-10-01 · 운영 반영 완료 · https://won-archive-weave.web.app/

## 사용할 수 있는 기능

- 자료 탐색: 개별 자료와 행사·자료 묶음·기록을 구분하고, 상세 검색 조건을 접어 모바일 이동량을 줄임
- 등록 진입: 과거 행사·자료 모음은 로그인한 뒤 작성. Google·네이버·카카오 선택과 복귀 경로 일치
- 홈: 목적 카드의 높이를 줄이고 최근 행사를 앞으로 배치. 첫 카드만 강조하던 색상 제거
- 파일 등록: 드래그앤드롭, 최대10개·각20MB·합계100MB, 잘못된 파일을 놓아도 기존 선택 유지, 실패한 파일만 재시도
- 등록 정보: ‘자료 제목’으로 통일, 권리자 예시 홍길동, 출처 선택 입력, 표시 이름은 권리자 이름 사용, 공유 근거 체크 선택
- 텍스트: 공백·탭·줄바꿈을 보존하는 방식이 기본. ‘제목·목록으로 정리’도 선택 가능하며 기존 서식 글 유지
- 작성 도움말: 방식별 입력/결과 예시 말풍선. 본문에 예시를 삽입하지 않으며 닫기·Escape·초점 복귀 지원
- 입력 표시: 체크박스를 첫 줄에 정렬하고 필수·선택은 색상 배지와 글자로 구분
- 오픈 안내: 확정 환영 문구, 첫 홈 방문 한 번, 직접 링크 방문 제외, 수동 다시 보기, 선택형 기능 소개3장
- 커뮤니티: ‘오픈 응원’ 전용 탭과 노란 별·New! 표시. 직접 글을 올리거나 댓글 참여. 환영 안내에서 이 게시판으로 연결

운영자의 후속 결정으로 응원은 단일 게시글 대신 전용 게시판에 모은다. 로그인 후 해당 탭으로 복귀하는 주소를 보존하며 자동 글·댓글 등록은 없다. 게시판의 필터는 현재 불러온 글에 적용되고 기존 ‘이전 글 더 보기’를 이용할 수 있다.

## 확인 결과
