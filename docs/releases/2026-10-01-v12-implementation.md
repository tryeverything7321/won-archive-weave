# 출시점검 v1.2 구현 체크포인트

2026-10-01 · 코드 저장 완료 · 신규 기능 운영 배포 전

파일 우선 자료 묶음 등록(10개·개별 20MB·합계 100MB), 파일별 재시도·교체·철회, 행사와 자료/활동 기록 연결, 연도만 아는 옛 행사 등록, 개최 연도와 업로드 연도를 구분한 탐색, 원본을 참조하는 자료 모음을 구현했다. 검사 전 파일은 격리 저장하며 공개 행사·모음에서도 하위 자료의 공개 범위를 유지한다.

## 확인한 범위

- 프런트 모델 테스트 256개 통과
- Functions 테스트 365개 통과·6개 환경 의존 시험 생략
- lint 오류 0, 생성된 서버 산출물의 기존 경고 4개
- 타입 검사, 프런트 빌드, Functions 빌드 통과
- 합성 Emulator: 연도만 있는 행사, 자료 6개·기록 2개 연결, 모음 간 같은 원본 참조, 비공개 자료 차단, 연결 해제 후 원본 보존 확인
- Storage 규칙: 소유자·예약·파일 버전 검사, 교체/철회 후 오래된 업로드와 덮어쓰기 차단 확인
- 합성 브라우저: 6개 중 실패한 파일 하나만 재업로드 확인

## 남은 확인과 배포

자료 상세·내 자료 관리의 전체 브라우저 통합, 독립 최종 검증, 실제 계정 업로드·스캐너·다운로드와 OAuth 왕복 검증은 남아 있다. 이 커밋은 운영 배포 완료를 뜻하지 않는다. 신규 서버·규칙·화면의 통합 배포 전이며 운영 데이터 이관은 실행하지 않았다.

기존 Google/가입/관리자 화면과 관련 서버 배포 상태는 기존 배포 기록을 따른다. 비밀 설정 연결이 자동 보안 검토에 차단되어 기존 OAuth·검사·제출·다운로드·미리보기 일부 서버의 후속 배포도 별도로 남아 있다.
