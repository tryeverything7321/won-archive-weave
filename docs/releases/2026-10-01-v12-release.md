# 자료 묶음·행사 아카이브 운영 배포

2026-10-01 · https://won-archive-weave.web.app/

## 사용할 수 있는 기능

- 자료 나눔 → 자료 올리기: 파일 먼저 선택, 제목 제안, 본문 선택 입력, 공통 출처·권한 한 번 입력
- 한 묶음에 최대 10개, 파일당 20MB, 합계 100MB. 실패한 파일만 재시도하며 성공 파일은 유지
- 내 위브 → 내 활동: 제목·공개 범위·파일 이름·순서 수정, 파일 교체·추가·개별 공개 중단
- 행사 상세: 자료 묶음·개별 자료·활동 기록을 함께 확인하고 행사 맥락에서 등록·연결
- 개최 연도와 업로드 연도 별도 탐색, 날짜를 모르는 옛 행사는 연도만 등록
- 자료 모음: 같은 원본을 여러 모음에 참조로 연결. 연결 해제는 원본 삭제와 구분
- 운영 센터 → 행사: 주최 표시 이름·다른 표기·활동 지역 관리

## 배포와 검증

서버 함수 104개, Firestore/Storage 규칙·인덱스, Hosting을 배포했다. 파일 검사·제출·다운로드·미리보기의 이전 미배포 변경도 이번 서버 목록에 포함했다. 기존 Naver/Kakao OAuth 진입점 5개는 갱신하지 않았다. 비밀 설정 파일을 읽지 않고 SDK 배포 명세의 공개 기본값과 기존 Secret Manager 연결을 사용했다.

라이브 검증: 11개 경로, 77개 JS/CSS 파일이 최종 빌드와 일치하며 비로그인 서버 가드 16개 통과. 엔트리 `index-DMOhJbJM.js`.

- 프런트 모델 256개, 타입 검사·빌드·lint 오류 0
- 서버 에뮬레이터 370개 통과·1개 생략. 생략된 Storage 예약 정리를 포함한 해당 시험군 6개는 별도로 모두 통과
- 행사 소유권·공개 범위 즉시 반영, 105개 동일 시각 자료 페이지 처리, 행사·모음 원본 보존 통합 시험 3개 통과
- 실제 React 합성 화면에서 개별 재시도·수정·교체·철회, 다음 페이지, 모음 저장 재시도, 키보드 상세/복귀 확인
- 모바일 390px 가로 넘침 없음. 자료 상세·내 관리 접근성 자동 검사 위반 0

라이브에서 선택하지 않은 검색 조건이 null로 전송되는 문제를 발견해 수정하고, 검색 HTTP 200·화면 오류 없음까지 재확인했다.

독립 검토에서 발견한 행사 소유권, 원본 행사 공개 상태, 목록 페이지 누락을 수정했다. 최종 검토는 추가 제품 코드 차단 결함이 없다고 보고했다. 작업 실행 계약에 사용자 업로드 한도 원문이 누락된 추적 문제는 별도 보완 기록으로 남기며 전체 출시점검 완료 판정으로 바꾸지 않는다.

## 남은 확인

실제 계정 Google OAuth 왕복, 실제 파일 검사 서비스의 업로드→검사→다운로드→철회 왕복, 실기기·스크린리더 검증은 미실행이다. 합성 브라우저·에뮬레이터 검증과 구분한다. 기존 운영 경보·Cloud 예산 설정과 원래 출시점검 미완료 범위도 유지한다. 운영 데이터 이관은 실행하지 않았다.

폴더째 가져오기·일괄 다운로드·공동 편집·담당자 인계는 후속 범위다.
